Patientenfeedback – Dr. Pickl & Dr. Roland

Webbasierte Anwendung zur freiwilligen Erstellung von Google-Bewertungen für die Facharztpraxis für Augenheilkunde Dr. Pickl & Dr. Roland.

Projektbeschreibung

Die Anwendung unterstützt Patientinnen und Patienten dabei, ihre persönlichen Erfahrungen mit der Ordination in eigenen Worten auf Google zu teilen.

Dazu werden vier kurze Fragen zu folgenden Bereichen gestellt:

Online-Terminbuchung

Organisation und Wartezeiten

Ordinationsteam

Ärztliche Betreuung

Zusätzlich kann ein individueller Kommentar eingegeben werden.

Aus den ausgewählten Antworten erstellt die Anwendung einen Bewertungsvorschlag mit unterschiedlichen sprachlichen Formulierungen. Der Text kann vor der Veröffentlichung vollständig bearbeitet werden.

Funktionsweise

Fragen beantworten.

Optional einen persönlichen Kommentar ergänzen.

Einen automatisch formulierten Bewertungsvorschlag erhalten.

Den Text prüfen, bearbeiten und kopieren.

Google öffnen und freiwillig eine Bewertung veröffentlichen.

Die Auswahl der Sterne und die Entscheidung über eine Veröffentlichung erfolgen ausschließlich durch die Nutzerinnen und Nutzer.

Datenschutz

Die Anwendung benötigt keine Registrierung.

Die Antworten werden ausschließlich im Browser verarbeitet.

Es werden keine Antworten in einer eigenen Datenbank gespeichert.

Es erfolgt keine Übertragung der Antworten an die Ordination.

Die Anwendung ist nicht mit der Praxissoftware verbunden.

Nutzerinnen und Nutzer werden gebeten, keine vertraulichen Gesundheitsdaten einzugeben.

Beim Aufruf der Anwendung und beim Wechsel zu Google gelten zusätzlich die Datenschutzbedingungen der jeweiligen Dienste.

Technische Umsetzung

Die Anwendung basiert auf HTML, CSS und JavaScript.

Es werden keine externen JavaScript-Bibliotheken, kein Backend und keine Datenbank benötigt.

Projektdatei: index(17).html

Hosting: GitHub Pages

Wartung und Aktualisierung

Änderungen an der Anwendung erfolgen über die Datei index.html im GitHub-Repository.

Nach dem Speichern und Veröffentlichen einer Änderung wird die aktualisierte Version über GitHub Pages bereitgestellt.

Hinweise

Die Anwendung dient ausschließlich als freiwillige Formulierungshilfe. Sie veröffentlicht keine Bewertungen automatisch und beeinflusst nicht die Auswahl der Google-Sterne.

Die Verantwortung für den endgültigen Bewertungstext und dessen Veröffentlichung liegt bei der jeweiligen Person.
